# 淡黄色儿童英语识别页设计

## 目标

把现有英语手写识别单页改造成适合小学生使用的温暖学习工具，同时完整保留选图、拍照、识别、编辑、导出和云端历史功能。

## 设计方向

- 使用奶油白、淡黄色、向日葵黄和少量天蓝色，形成“阳光作业本”的视觉感受。
- 首屏只强调一个主要动作“拍照识别”，并提供次要动作“选择照片”。
- 四步流程改为儿童可快速理解的“选照片、识别、检查、完成”。
- 上传区域使用手机拍摄英语笔记的原创插画，避免使用表情符号和占位图。
- 历史记录改称“最近的学习”，编辑和完成页面沿用同一套视觉语言。

## 约束

- 不修改识别接口、数据结构、Word 导出和云端存储逻辑。
- 不新增页面或复杂功能。
- 移动端优先，同时保持桌面浏览器可用。
